Gym Membership Churn Prediction and Analysis

Machine learning as a decision-support demonstration

This project explores whether available membership characteristics are associated with the churn label in a gym dataset. It provides data inspection, model comparison, held-out evaluation, and a form that runs inference with the saved preprocessing and classifier pipeline.

Limitations

The dataset is synthetic, so its statistics and model results do not establish real-world gym behavior or performance. Churn predictions are estimates—not guarantees—and no validated intervention threshold has been defined. A model score alone should not determine how a real member is treated.
